# Mohit Vaswani — Portfolio

Personal portfolio built with [Astro](https://astro.build).

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:4321.

## Edit content

- Products and socials: `src/data.ts`
- Bio and layout: `src/pages/index.astro`
- Profile photo: `public/avatar.jpg`

Social icons come from [Simple Icons](https://simpleicons.org) via Iconify.
